## Approved Gate

### Preparation Tasks

Preparation, research, inspection, decision-package, QA-planning, and documentation work may proceed under a lighter readiness review.

### Feature Implementation Tasks

Feature implementation may proceed only when the full twelve-condition readiness gate has been reviewed and the Project Manager records one of the following statuses:

* `READY`
* `READY WITH CONDITIONS`
* `BLOCKED`

A failed readiness condition must result in either `READY WITH CONDITIONS` or `BLOCKED`; it must never be silently treated as `READY`.
